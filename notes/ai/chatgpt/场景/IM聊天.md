# 场景面试：IM / 聊天

---

## 1. 架构

```text
客户端 ←长连接→ 接入层（Netty/WebSocket/Gateway）
              ↓
         消息服务 → MQ → 存储（HBase/MySQL/时序）
              ↓
         推送到对方在线设备
```

---

## 2. 核心问题

| 问题 | 方案 |
|------|------|
| **消息顺序** | 单聊：会话 id 单 partition MQ；seq 递增 |
| **至少一次** | clientMsgId 去重 |
| **离线** | 存离线表；上线拉取 |
| **已读** | 读扩散回执；Redis 存 lastReadSeq |
| **群聊** | 写扩散 vs 读扩散；大群只存一条 |

---

## 3. 事务

- 存消息 + 更新会话 **本地事务**  
- 推送 **异步**；失败重试

---

## 4. 缓存

- 最近消息 Redis List  
- 在线状态 Redis Set / 心跳

---

## 5. 高并发

- 接入层水平扩展  
- 消息 MQ 削峰  
- 大群：**合并推送**、限制 @ 全员

---

## 6. 读写分离

- 历史消息读从/HBase  
- 写主

**收口**：「长连接接入；MQ 顺序；clientMsgId 幂等；离线拉取。」
