# 场景面试：短链

---

## 1. 流程

```text
长 URL → 生成短码（62 进制 / Hash）→ 存 mapping
访问短链 → 302 跳长 URL（统计 PV）
```

---

## 2. 生成策略

| 方式 | 说明 |
|------|------|
| **哈希+冲突** | MurmurHash → base62；冲突则加盐重算 |
| **发号** | 雪花 id → base62（无冲突） |

---

## 3. 存储

- Redis：`short:{code}` → longUrl  
- MySQL 持久化；**读多写少**

---

## 4. 高并发读

- Redis 扛 302 查询  
- 本地缓存热点短码  
- CDN 边缘（高级）

---

## 5. 统计

- 异步 MQ 记录点击（IP、UA、时间）  
- **最终一致**；允许丢少量日志

---

## 6. 301 vs 302

- **302** 可变更目标、统计；SEO 用 301

**收口**：「发号或哈希；Redis 读；302+异步统计。」
