# 场景面试：缓存（穿透 / 击穿 / 雪崩 / 一致性）

---

## 1. 三大问题

| 问题 | 现象 | 方案 |
|------|------|------|
| **穿透** | 查不存在的数据，打穿到 DB | 布隆过滤器；空值缓存短 TTL |
| **击穿** | 热点 Key 过期瞬间并发打 DB | 互斥锁重建；逻辑过期（异步刷） |
| **雪崩** | 大量 Key 同时过期 / Redis 宕机 | TTL 随机；集群；多级缓存；降级 |

---

## 2. 一致性策略

| 策略 | 说明 |
|------|------|
| **Cache Aside** | 读 miss 加载；**写 DB 后删缓存**（常用） |
| **延迟双删** | 删 → 写 DB → sleep → 再删（主从延迟） |
| **Canal/Debezium** | 监听 binlog 更新/删缓存 |
| **先更 DB 再删缓存** | 推荐顺序；删失败重试 |

**强一致**场景（库存、余额）：**不以缓存为扣减依据**，缓存只作展示。

---

## 3. 与读写分离

- 删缓存后读从库 **旧数据** 回填缓存 → **双删** 或 写后 **读主** 再填  
- 关键链路：写主 + 删缓存 + 短暂读主

---

## 4. 高并发

- 本地 Caffeine + Redis 二级  
- 热点探测自动加本地缓存  
- Redis Cluster；避免 Big Key

---

## 5. 场景举例

| 场景 | 策略 |
|------|------|
| 商品详情 | 布隆 + Cache Aside |
| 库存展示 | 短 TTL；扣减删缓存 |
| 配置 | 长 TTL + 推送失效 |
| 秒杀库存 | Redis 为主，见秒杀 |

**收口**：「穿透布隆/空值；击穿互斥或逻辑过期；雪崩 TTL 抖动；写后删缓存+Canal。」
