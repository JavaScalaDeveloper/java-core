# 场景面试：对账 / 清结算

---

## 1. 场景

- **支付对账**：微信/支付宝账单 vs 内部 payment  
- **退款对账**  
- **清结算**：平台、商户、分账（电商 marketplace）

---

## 2. 对账流程

```text
T+1 拉渠道对账文件
  解析 → 与 payment 按 channel_trade_no 匹配
  平账 / 长款（渠道有内部无）/ 短款（内部有渠道无）
  → 差错表 → 自动补单或人工
```

---

## 3. 技术要点

| 点 | 说明 |
|----|------|
| **幂等** | 补单不能重复推进订单 |
| **事务** | 差错处理本地事务 + 审计日志 |
| **读写** | 对账跑 **只读从库/离线库** |
| **大数据量** | 分片、批量、MapReduce/Spark |

---

## 4. 分账

- 支付成功 → 子商户分账 API  
- 分账失败 **重试 + 对账**  
- 与订单 **最终一致**

---

## 5. 面试收口

「T+1 文件对账；三态差错；补单幂等；在线写主、对账读从/离线。」
