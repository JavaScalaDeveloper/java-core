# 场景面试：短信 / 验证码

---

## 1. 流程

```text
请求验证码 → 频控校验 → 生成 6 位码 → Redis 存 code+TTL
  → 调短信网关 → 用户提交 → 比对 Redis → 删除/一次性
```

---

## 2. 防刷

| 维度 | 规则 |
|------|------|
| 手机号 | 1 条/60s，10 条/天 |
| IP | 100 条/天 |
| 设备 | deviceId 限流 |
| 图形验证码 | 触发阈值后必过 |

Redis：`INCR sms:limit:{phone}:{day}` + EXPIRE

---

## 3. 安全

- 验证码 **6 位随机**；5 分钟过期  
- 错误次数锁定  
- 不在日志打明文 code  
- 防 **短信轰炸**（接口鉴权 + 频控）

---

## 4. 事务

- 无强事务；发失败可重试（注意重复短信成本）  
- 记录发送日志对账

---

## 5. 高并发

- 发送 **异步 MQ** 调网关（削峰）  
- 多供应商 failover

**收口**：「Redis 存码+多维度频控；异步发送；防轰炸。」
