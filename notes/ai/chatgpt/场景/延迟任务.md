# 场景面试：延迟任务 / 定时关单

---

## 1. 典型场景

- **支付超时关单**（30 分钟）  
- 自动确认收货（7 天）  
- 订单催付、优惠券过期提醒

---

## 2. 实现方案

| 方案 | 说明 |
|------|------|
| **RocketMQ 延迟消息** | 18 级延迟；精确度有限 |
| **RabbitMQ TTL+DLX** | 灵活 |
| **Redis ZSet** | score=执行时间，定时 scan |
| **时间轮** | Netty HashedWheelTimer；内存 |
| **XXL-Job / Scheduler** | 扫表 `WHERE status=WAIT_PAY AND create_time<?` |
| **DB 定时任务** | 简单可靠；扫表有压力需分片 |

---

## 3. 关单链路

```text
下单成功 → 发延迟 MQ（30min）
  → 消费：查 order 仍 WAIT_PAY → 关单 + 释放库存 + 退券
  → 幂等 order_id
```

**注意**：已支付不能关 → 状态机判断。

---

## 4. 事务

- 关单 **本地事务** 改 order  
- 释放库存 **RPC**；失败重试  
- 不用全局事务

---

## 5. 高并发

- 扫表 **分片**（order_id % N）  
- 延迟 MQ 堆积扩消费者  
- 避免 **集中过期** 打爆（随机抖动几分钟）

---

## 6. 与缓存

- 关单删订单缓存

**收口**：「延迟 MQ 或扫表；消费幂等+状态判断；释放库存补偿。」
