# 场景面试：直播 / 弹幕

---

## 1. 链路

```text
推流 → CDN/RTMP/SRT → 转码 → 多码率 HLS/FLV
拉流 → CDN 边缘
弹幕 → WebSocket/QUIC → 弹幕服务 → 广播房间
礼物 → 扣虚拟币（事务）→ 动画 MQ → 结算
```

---

## 2. 弹幕高并发

- 房间 **消息合并**（100ms 一批）  
- 限流：用户发送频率  
- 热点房间：**分片广播**  
- 敏感词 **异步过滤**（先展示后撤回 vs 先审后发）

---

## 3. 礼物 / 交易

- 扣币 **本地事务** 或 TCC  
- 与主播分成 **MQ 最终一致**  
- 幂等：gift_order_id

---

## 4. 缓存

- 房间在线人数 HyperLogLog / 近似  
- 榜单 Redis ZSet

---

## 5. 读写分离

- 直播元数据读从  
- 礼物流水写主

**收口**：「CDN 扛流；弹幕合并+限流；礼物本地事务+分成 MQ。」
