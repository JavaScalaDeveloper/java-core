# 场景面试：搜索

---

## 1. 链路

```text
MySQL/业务库 → Canal/MQ → ES 索引
用户 query → 网关 → 搜索服务 → ES
         ↓ 降级
      DB 简单 LIKE / 热搜缓存
```

---

## 2. 核心点

| 点 | 说明 |
|----|------|
| **近实时** | 秒级延迟可接受；全量+增量 |
| **分词** | IK 等；同义词、纠错 |
| **排序** | 相关度 + 销量 + 个性化（学习排序） |
| **分页** | `search_after` 深分页，不用大 from |
| **高亮** | ES highlight |

---

## 3. 一致性

- ES 与 DB **最终一致**  
- 下单/上下架：MQ 更新索引  
- 失败重试 + 全量对账修复

---

## 4. 缓存

- 热搜词、默认推荐：Redis  
- 热门 query 结果短缓存（注意个性化）

---

## 5. 高并发

- ES 水平扩展分片  
- 限流；降级关个性化  
- 读写：ES 读为主；写索引异步

---

## 6. 读写分离

- 商品源数据 MySQL 主从  
- 搜索不走 MySQL 在线库（除降级）

**收口**：「Canal/MQ 同步 ES；最终一致；深分页 search_after；峰值限流降级。」
