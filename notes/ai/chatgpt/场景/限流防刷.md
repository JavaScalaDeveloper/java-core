# 场景面试：限流 / 防刷 / 风控

---

## 1. 层次

```text
CDN/WAF → Nginx → Gateway(Sentinel) → 应用(Sentinel) → 下游
```

---

## 2. 算法

| 算法 | 场景 |
|------|------|
| 令牌桶 | 允许突发；Gateway Redis |
| 漏桶 | 匀速；排队 |
| 滑动窗口 | Sentinel 统计 |
| 计数器 | 短信/登录频控 |

见 `../basics/SpringCloud.md` Sentinel 单机/集群限流。

---

## 3. 维度

- IP、userId、deviceId、接口、商户  
- **集群限流** Token Server 全局限额

---

## 4. 防刷

- 验证码、滑块  
- 设备指纹、行为序列（风控引擎）  
- 黑名单 Redis Set

---

## 5. 与业务

- 秒杀：独立限流阈值  
- 支付回调：验签 + IP 白名单  
- 领券：用户维度 QPS

---

## 6. 降级

- 超限 **快速失败** 429；友好排队页  
- 非核心接口关闭

**收口**：「多层限流；Sentinel 单机+集群；频控+验证码+风控。」
