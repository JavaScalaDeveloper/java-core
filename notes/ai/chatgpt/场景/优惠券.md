# 场景面试：优惠券 / 红包

---

## 1. 核心挑战

- **领取防超发**（总量、每人限领）  
- **核销幂等**（同一订单不能重复扣券）  
- **并发领取** 热点  
- 与 **下单/支付** 一致

---

## 2. 领取链路

```text
校验活动有效 → Redis DECR 库存（或 Lua 判断 per-user 限领）
  → 成功则 DB INSERT coupon_user
  → 失败回滚 Redis
```

| 防超发 | 实现 |
|--------|------|
| 总量 | Redis 库存 + DB 唯一约束 |
| 每人 N 张 | Redis `HINCRBY user:count` 或 DB `(activity_id,user_id)` 计数 |

---

## 3. 核销

- **下单时核销**（与订单同事务，同库最佳）  
- 跨库：TCC Try 锁券 / 或 下单后 MQ 核销（有重复风险需幂等）  
- `UPDATE coupon_user SET status=USED WHERE id=? AND status=UNUSED`

---

## 4. 退回

- 关单/全额退：**券退回** UNUSED（幂等）  
- 部分退：按规则是否退券

---

## 5. 缓存

- 活动规则、券模板：Redis + 本地  
- 用户券列表：Redis 缓存，领取/核销后删

---

## 6. 高并发

- 领券接口 **限流** + 验证码  
- 热点活动：**库存分桶**（多个 Redis key 汇总）

---

## 7. 分布式事务

- 券与订单 **同库** → 本地事务  
- 异库 → 优先 **下单时同步核销** RPC + 失败不建单；或 Seata AT 短事务

**收口**：「领取 Redis+DB 双扣；核销与订单同事务或预占；退回走关单/退款。」
