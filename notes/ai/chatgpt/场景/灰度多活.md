# 场景面试：灰度发布 / 异地多活

---

## 1. 灰度

| 手段 | 说明 |
|------|------|
| **Gateway 路由** | Header `version=v2` → 新版本实例 |
| **Nacos metadata** | LoadBalancer 过滤标签 |
| **配置开关** | Nacos 百分比放量 |
| **金丝雀** | 1% 流量 → 观察 → 扩大 |

---

## 2. 异地多活

- **单元化**：userId 路由到固定机房（就近写）  
- **数据同步**：DTS/自研；**冲突解决**（LWW、业务合并）  
- **RPO/RTO**：可接受丢秒级 vs 零丢

---

## 3. 缓存

- 多活 **Redis 不共享写** 或 CRDT/双向同步（复杂）  
- 常 **单元内 Redis** + 全局配置中心

---

## 4. 分布式事务

- 跨机房 **避免强事务**  
- 单元内本地事务；跨单元 MQ

---

## 5. 读写分离

- 单元内主从；跨单元读本地从库

**收口**：「流量染色灰度；多活单元化+异步同步；跨单元最终一致。」
