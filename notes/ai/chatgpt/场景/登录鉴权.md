# 场景面试：登录 / 注册 / 鉴权

---

## 1. 方案对比

| 方案 | 特点 |
|------|------|
| **Session** | 服务端存；粘滞/Redis 共享 Session |
| **JWT** | 无状态；难主动失效；需短过期+refresh |
| **OAuth2/OIDC** | 第三方登录、SSO |

---

## 2. 登录流程

```text
账密/短信/OAuth → 校验 → 发 access_token + refresh_token
  → Redis 存 refresh / 黑名单（踢下线）
  → 网关校验 JWT 或 调鉴权服务
```

---

## 3. 安全

- 密码 bcrypt/Argon2；盐  
- 防暴力：限流 + 锁定 + 验证码  
- HTTPS；HttpOnly Cookie（Web）  
- CSRF、XSS 防护

---

## 4. 缓存

- Session/Token 黑名单 Redis  
- 用户信息短缓存（权限变更删缓存）  
- 权限列表：本地 + Redis

---

## 5. 读写分离

- 注册写主；用户信息读从（可接受延迟）  
- 改密码 **删全端 token**（Redis 黑名单 version）

---

## 6. 高并发

- 登录接口限流  
- Redis 扛 Session  
- 验证码见 [短信验证码.md](./短信验证码.md)

---

## 7. 分布式

- 多机房：**Redis 同步** 或 JWT 无状态  
- SSO：统一认证中心 + ticket

**收口**：「JWT+refresh+Redis 黑名单；限流防刷；改密失效 token。」
