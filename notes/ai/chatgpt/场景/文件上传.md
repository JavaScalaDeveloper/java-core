# 场景面试：文件 / 图片上传

---

## 1. 直传 OSS（推荐）

```text
客户端请求后端拿 STS 临时凭证 + objectKey
  → 直传 OSS/S3（不经业务带宽）
  → 回调或客户端通知后端写 file 元数据
```

---

## 2. 分片 / 断点续传

- 大文件：init multipart → upload parts → complete  
- 记录 uploadId、已传 part 到 Redis/DB  
- 秒传：MD5 查重已有 object

---

## 3. 事务

- 元数据写 DB **本地事务**  
- 文件本身在 OSS（最终一致：回调失败则定时清理孤儿 object）

---

## 4. 缓存 / CDN

- 静态 URL + **CDN** 加速  
- 私有文件：签名 URL 短 TTL

---

## 5. 高并发

- 直传不打穿应用服务器  
- 凭证接口限流  
- 图片处理异步（缩略图 MQ）

---

## 6. 安全

- 类型/大小校验；病毒扫描（异步）  
- 防 SSRF（拉取远程 URL 上传）

**收口**：「STS 直传 OSS；分片断点；元数据 DB；CDN 读。」
