# 设计模式面试笔记

23 种 GoF 模式 + 六大原则 + Spring 中的模式。面试重点 **8 种高频**，其余 **一张表速背**。

---

# 一、六大原则（SOLID + 常见）

| 原则 | 一句话 |
|------|--------|
| **单一职责** | 一个类只干一类事 |
| **开闭原则** | 对扩展开放，对修改关闭 |
| **里氏替换** | 子类可替换父类使用 |
| **依赖倒置** | 依赖抽象，不依赖具体 |
| **接口隔离** | 接口要细，别强迫实现无用方法 |
| **迪米特法则** | 少知道别人细节，降低耦合 |
| **合成复用** | 优先组合/聚合，少用继承 |

# 三、高频 8 种（深入）

## 1. 单例模式

**目的：** 进程内唯一实例，节省资源、统一状态。

| 写法 | 特点 |
|------|------|
| 饿汉 | 类加载即创建；简单；可能浪费 |
| 懒汉 | 用时创建；要线程安全 |
| **双重检查锁 DCL** | volatile + synchronized；经典面试 |
| **静态内部类** | 懒加载、线程安全、推荐 |
| **枚举** | 防反射/序列化破坏；Effective Java 推荐 |

```java
// 静态内部类
public class Singleton {
    private Singleton() {}
    private static class Holder {
        static final Singleton INSTANCE = new Singleton();
    }
    public static Singleton get() { return Holder.INSTANCE; }
}
```

**追问：** 反射/序列化如何破坏？枚举为何安全？

## 2. 工厂模式家族

| | 简单工厂 | 工厂方法 | 抽象工厂 |
|--|----------|----------|----------|
| 创建 | 一个工厂类 if/switch | 子类工厂各建产品 | 一族产品 |
| Spring | BeanFactory 思想 | FactoryBean | 不同 Starter 套件 |

---

## 3. 策略模式

**定义：** 算法族封装，可互换，独立于使用方。

```java
interface PayStrategy { void pay(int amount); }
// 上下文持有策略，运行时切换
```

**vs 状态模式：** 策略由 **客户端** 切换算法；状态由 **状态自身** 驱动流转。

**Spring：** `Resource` 加载策略、各种 `XXXStrategy`。

---

## 4. 代理模式

| 类型 | 实现 | 场景 |
|------|------|------|
| 静态代理 | 手写代理类 | 简单增强 |
| **JDK 动态代理** | 接口 + InvocationHandler | Spring AOP 默认 |
| **CGLIB** | 子类继承 | 无接口的类 |

**Spring AOP：** 默认接口用 JDK，否则 CGLIB。

---

## 5. 观察者模式

**Subject 维护 Observer 列表，状态变则 notify。**

- Java：`Observer/Observable`（旧）、`PropertyChangeListener`  
- Spring：`ApplicationEvent` + `ApplicationListener`  
- MQ：发布订阅  

**vs 发布订阅：** 观察者常直接耦合 Subject；发布订阅多经 **Broker** 解耦。

---

## 6. 装饰器模式

**动态包装，叠加功能，同接口。**

- `InputStream` → `BufferedInputStream` → `GZIPInputStream`  
- **vs 代理：** 装饰侧重 **增强功能**；代理侧重 **访问控制**（概念可重叠）。

---

## 7. 模板方法模式

**父类定义流程骨架 `final`，子类实现抽象步骤。**

```java
public final void workOneDay() {
    enter(); work(); exit(); // work() 子类实现
}
```

`HttpServlet`：`service()` 模板，`doGet/doPost` 钩子。

---

## 8. 责任链模式

**请求沿链传递，直到有人处理。**

- Servlet `Filter` 链  
- Netty `ChannelPipeline`  
- 审批流、日志级别链  

**注意：** 链过长要控制；要有兜底 handler。

# 四、其他常考对比

| 对比 | 区别 |
|------|------|
| 装饰 vs 代理 | 增强 vs 控制访问 |
| 策略 vs 状态 | 外部换算法 vs 内部状态驱动 |
| 桥接 vs 适配器 | 设计期解耦抽象与实现 vs 已有类接口不兼容 |
| 组合 vs 继承 | 树形整体-部分 vs is-a |
| 建造者 vs 工厂 | 分步组装复杂对象 vs 创建产品 |
