# 算法（Java 简化版）

写法原则：能递归就递归；少写辅助类；面试能口述、能手写。

---

## 1. 快排

### 调用入口（对外）

```java
void sort(int[] a) {
    if (a == null || a.length <= 1) return;
    quickSort(a, 0, a.length - 1);  // 闭区间 [0, n-1]
}
```

### 核心递归

```java
void quickSort(int[] a, int l, int r) {
    if (l >= r) return;                         // 0 或 1 个元素，有序
    int i = l, j = r, p = a[l + r >> 1];         // 取中点作 pivot
    while (i <= j) {
        while (a[i] < p) i++;                   // 左找 >= p
        while (a[j] > p) j--;                   // 右找 <= p
        if (i <= j) {
            int t = a[i]; a[i] = a[j]; a[j] = t;
            i++; j--;
        }
    }
    // 结束后：a[l..j] 都 <= p，a[i..r] 都 >= p，中间可能空或相等段
    quickSort(a, l, j);                         // 排左半
    quickSort(a, i, r);                         // 排右半
}
```

### 完整调用逻辑（口述）

```text
sort(a)
  └─ quickSort(a, 0, n-1)
        ├─ 选 pivot，双指针交换，把区间分成左右两部分
        ├─ quickSort(a, l, j)     // 递归左
        │     └─ … 直到 l >= r 返回
        └─ quickSort(a, i, r)     // 递归右
              └─ … 直到 l >= r 返回
```

**一次 partition 示例**（`a=[3,1,4,2]`，`l=0,r=3`，`p=a[1]=1` 仅示意思路；实际 pivot 取中点）：

1. 双指针相遇后得到分界 `j`、`i`。  
2. 先递归排 `[l,j]`，再递归排 `[i,r]`。  
3. 每层只保证「相对 pivot 的大小关系」，整体有序靠不断缩小区间。

**复杂度**：平均 O(n log n)，最坏 O(n²)（已有序且 pivot 极偏）；空间 O(log n) 递归栈。

## 2. 归并排序

### 调用入口（对外）

```java
void sort(int[] a) {
    if (a == null || a.length <= 1) return;
    int[] tmp = new int[a.length];              // 全程复用一块临时数组
    mergeSort(a, 0, a.length - 1, tmp);         // 闭区间 [0, n-1]
}
```

### 核心递归（先拆后合）

```java
void mergeSort(int[] a, int l, int r, int[] tmp) {
    if (l >= r) return;                         // 单点，无需再拆
    int m = l + r >> 1;
    mergeSort(a, l, m, tmp);                    // ① 排左半 [l, m]
    mergeSort(a, m + 1, r, tmp);                // ② 排右半 [m+1, r]
    // ③ 合并两个有序段 → tmp，再拷回 a
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = l; i <= r; i++) a[i] = tmp[i];
}
```

### 完整调用逻辑（口述）

```text
sort(a)
  └─ 申请 tmp[n]
  └─ mergeSort(a, 0, n-1, tmp)
        ├─ mergeSort(左半)          // 一直拆到长度为 1
        │     └─ …
        ├─ mergeSort(右半)
        │     └─ …
        └─ merge：两段有序表二路归并到 tmp，再写回 a[l..r]
```

**调用树示例**（`n=4`，下标 `0..3`）：

```text
mergeSort(0,3)
  ├─ mergeSort(0,1)
  │    ├─ mergeSort(0,0) return
  │    ├─ mergeSort(1,1) return
  │    └─ merge [0] 与 [1]
  ├─ mergeSort(2,3)
  │    ├─ mergeSort(2,2) return
  │    ├─ mergeSort(3,3) return
  │    └─ merge [2] 与 [3]
  └─ merge [0..1] 与 [2..3]
```

**注意**：必须「左右都排完」再 merge；`tmp` 在入口只建一次，避免每层 `new`。

**复杂度**：稳定 O(n log n)；额外空间 O(n)；稳定排序（相等元素相对顺序可保留，代码里用 `<=`）。

## 3. 二分查找

```java
// 找 target，找不到返回 -1
int binarySearch(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l <= r) {
        int m = l + r >> 1;
        if (a[m] == target) return m;
        if (a[m] < target) l = m + 1;
        else r = m - 1;
    }
    return -1;
}

// 递归版
int binarySearch(int[] a, int l, int r, int target) {
    if (l > r) return -1;
    int m = l + r >> 1;
    if (a[m] == target) return m;
    return a[m] < target
        ? binarySearch(a, m + 1, r, target)
        : binarySearch(a, l, m - 1, target);
}

// 左边界：第一个 >= target
int lowerBound(int[] a, int target) {
    int l = 0, r = a.length;
    while (l < r) {
        int m = l + r >> 1;
        if (a[m] < target) l = m + 1;
        else r = m;
    }
    return l;
}
```

## 4. 回溯法（全排列 / 组合总和模板）

```java
// 全排列
void permute(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        permute(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}

// 组合总和（可重复选，候选已排序）
void combinationSum(int[] c, int start, int remain, List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < c.length && c[i] <= remain; i++) {
        path.add(c[i]);
        combinationSum(c, i, remain - c[i], path, res); // i：可重复；i+1：不可重复
        path.remove(path.size() - 1);
    }
}
```

## 5. 翻转链表

```java
ListNode reverse(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverse(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}

// 迭代
ListNode reverseIter(ListNode head) {
    ListNode pre = null, cur = head;
    while (cur != null) {
        ListNode nxt = cur.next;
        cur.next = pre;
        pre = cur;
        cur = nxt;
    }
    return pre;
}
```

## 6. 链表每 k 个一组翻转

```java
ListNode reverseKGroup(ListNode head, int k) {
    ListNode p = head;
    for (int i = 0; i < k; i++) {
        if (p == null) return head; // 不足 k 不翻
        p = p.next;
    }
    ListNode newHead = reversePart(head, p); // 翻 [head, p)
    head.next = reverseKGroup(p, k);
    return newHead;
}

// 翻转到 end（不含），返回新头
ListNode reversePart(ListNode start, ListNode end) {
    ListNode pre = end, cur = start;
    while (cur != end) {
        ListNode nxt = cur.next;
        cur.next = pre;
        pre = cur;
        cur = nxt;
    }
    return pre;
}
```

## 8. BFS（层序遍历 / 最短路模板）

```java
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int n = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            TreeNode t = q.poll();
            level.add(t.val);
            if (t.left != null) q.offer(t.left);
            if (t.right != null) q.offer(t.right);
        }
        res.add(level);
    }
    return res;
}

// 网格最短路（每步代价 1）
int bfs(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    if (grid[0][0] == 1) return -1;
    Queue<int[]> q = new ArrayDeque<>();
    boolean[][] vis = new boolean[m][n];
    q.offer(new int[]{0, 0, 0}); // r,c,dist
    vis[0][0] = true;
    int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
    while (!q.isEmpty()) {
        int[] cur = q.poll();
        if (cur[0] == m - 1 && cur[1] == n - 1) return cur[2];
        for (int[] dir : d) {
            int x = cur[0] + dir[0], y = cur[1] + dir[1];
            if (x < 0 || y < 0 || x >= m || y >= n || vis[x][y] || grid[x][y] == 1) continue;
            vis[x][y] = true;
            q.offer(new int[]{x, y, cur[2] + 1});
        }
    }
    return -1;
}
```

## 9. 约瑟夫环

```java
// 递归：f(n,m) = (f(n-1,m) + m) % n，返回最后剩下的下标（0-based）
int josephus(int n, int m) {
    if (n == 1) return 0;
    return (josephus(n - 1, m) + m) % n;
}

// 链表模拟
int josephusList(int n, int m) {
    ListNode head = new ListNode(0), p = head;
    for (int i = 1; i < n; i++) p = (p.next = new ListNode(i));
    p.next = head;
    while (p.next != p) {
        for (int i = 1; i < m; i++) p = p.next;
        p.next = p.next.next; // 删掉第 m 个
    }
    return p.val;
}
```

## 10. 回文串

```java
// 判断
boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
    return true;
}

// 最长回文子串：中心扩展
String longestPalindrome(String s) {
    String ans = "";
    for (int i = 0; i < s.length(); i++) {
        String a = expand(s, i, i);
        String b = expand(s, i, i + 1);
        if (a.length() > ans.length()) ans = a;
        if (b.length() > ans.length()) ans = b;
    }
    return ans;
}
String expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return s.substring(l + 1, r);
}

// 回文子串个数（中心扩展）
int countSubstrings(String s) {
    int cnt = 0;
    for (int i = 0; i < s.length(); i++) {
        cnt += expandCount(s, i, i) + expandCount(s, i, i + 1);
    }
    return cnt;
}
int expandCount(String s, int l, int r) {
    int c = 0;
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { c++; l--; r++; }
    return c;
}
```

## 11. 背包问题

```java
// 0-1 背包：容量 W，重量 w[]，价值 v[]
int knapsack01(int W, int[] w, int[] v) {
    int[] dp = new int[W + 1];
    for (int i = 0; i < w.length; i++)
        for (int j = W; j >= w[i]; j--)
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    return dp[W];
}

// 完全背包（每种无限件）：内层正序
int knapsackComplete(int W, int[] w, int[] v) {
    int[] dp = new int[W + 1];
    for (int i = 0; i < w.length; i++)
        for (int j = w[i]; j <= W; j++)
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    return dp[W];
}
```

## 12. 打家劫舍

```java
// 线性：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
int rob(int[] nums) {
    int pre = 0, cur = 0;
    for (int x : nums) {
        int t = Math.max(cur, pre + x);
        pre = cur;
        cur = t;
    }
    return cur;
}

// 环形：max(偷 [0..n-2], 偷 [1..n-1])
int robCircle(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    return Math.max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
}
int robRange(int[] a, int l, int r) {
    int pre = 0, cur = 0;
    for (int i = l; i <= r; i++) {
        int t = Math.max(cur, pre + a[i]);
        pre = cur; cur = t;
    }
    return cur;
}

// 二叉树：返回 [不偷该节点最大值, 偷该节点最大值]
int robTree(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}
int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] L = dfs(node.left), R = dfs(node.right);
    int notRob = Math.max(L[0], L[1]) + Math.max(R[0], R[1]);
    int rob = node.val + L[0] + R[0];
    return new int[]{notRob, rob};
}
```

## 13. 最长公共子序列（LCS）

```java
int lcs(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                ? dp[i - 1][j - 1] + 1
                : Math.max(dp[i - 1][j], dp[i][j - 1]);
    return dp[m][n];
}

// 滚动数组
int lcs2(String a, String b) {
    int n = b.length();
    int[] dp = new int[n + 1];
    for (int i = 1; i <= a.length(); i++) {
        int pre = 0;
        for (int j = 1; j <= n; j++) {
            int tmp = dp[j];
            dp[j] = a.charAt(i - 1) == b.charAt(j - 1)
                ? pre + 1 : Math.max(dp[j], dp[j - 1]);
            pre = tmp;
        }
    }
    return dp[n];
}
```

## 14. 最小路径和

```java
int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (i == 0 && j == 0) continue;
            else if (i == 0) grid[i][j] += grid[i][j - 1];
            else if (j == 0) grid[i][j] += grid[i - 1][j];
            else grid[i][j] += Math.min(grid[i - 1][j], grid[i][j - 1]);
        }
    return grid[m - 1][n - 1];
}

// 递归 + 记忆化
int minPathSumMemo(int[][] g, int i, int j, Integer[][] memo) {
    if (i == 0 && j == 0) return g[0][0];
    if (memo[i][j] != null) return memo[i][j];
    int best = Integer.MAX_VALUE;
    if (i > 0) best = Math.min(best, minPathSumMemo(g, i - 1, j, memo));
    if (j > 0) best = Math.min(best, minPathSumMemo(g, i, j - 1, memo));
    return memo[i][j] = g[i][j] + best;
}
```

## 15. 接雨水

```java
// 双指针 O(n)
int trap(int[] h) {
    int l = 0, r = h.length - 1, lMax = 0, rMax = 0, ans = 0;
    while (l < r) {
        lMax = Math.max(lMax, h[l]);
        rMax = Math.max(rMax, h[r]);
        if (lMax < rMax) ans += lMax - h[l++];
        else ans += rMax - h[r--];
    }
    return ans;
}

// 单调栈
int trapStack(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();
    int ans = 0;
    for (int i = 0; i < h.length; i++) {
        while (!st.isEmpty() && h[i] > h[st.peek()]) {
            int mid = st.pop();
            if (st.isEmpty()) break;
            int left = st.peek();
            int w = i - left - 1;
            int ht = Math.min(h[left], h[i]) - h[mid];
            ans += w * ht;
        }
        st.push(i);
    }
    return ans;
}
```

## 16. 多线程顺序打印 ABC

```java
// 三个线程循环打印 A B C，各 n 次
class PrintABC {
    private int state = 0; // 0->A, 1->B, 2->C
    private final int n;
    PrintABC(int n) { this.n = n; }

    synchronized void print(char c, int target) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            while (state % 3 != target) wait();
            System.out.print(c);
            state++;
            notifyAll();
        }
    }

    public static void main(String[] args) {
        PrintABC p = new PrintABC(5);
        new Thread(() -> { try { p.print('A', 0); } catch (Exception ignored) {} }).start();
        new Thread(() -> { try { p.print('B', 1); } catch (Exception ignored) {} }).start();
        new Thread(() -> { try { p.print('C', 2); } catch (Exception ignored) {} }).start();
    }
}
```

## 17. 生产者消费者

```java
class BoundedBuffer<T> {
    private final Queue<T> q = new ArrayDeque<>();
    private final int cap;
    BoundedBuffer(int cap) { this.cap = cap; }

    synchronized void put(T x) throws InterruptedException {
        while (q.size() == cap) wait();
        q.offer(x);
        notifyAll();
    }

    synchronized T take() throws InterruptedException {
        while (q.isEmpty()) wait();
        T x = q.poll();
        notifyAll();
        return x;
    }
}

// 用法示意
// new Thread(() -> { for (;;) buf.put(produce()); }).start();
// new Thread(() -> { for (;;) consume(buf.take()); }).start();
```

BlockingQueue 一行版：`new ArrayBlockingQueue<>(cap)`，`put` / `take` 自带阻塞。

## 18. N 字形转换

```java
// 字符串按 N 行 Z 字形排列后按行读出
String convert(String s, int numRows) {
    if (numRows == 1 || numRows >= s.length()) return s;
    StringBuilder[] rows = new StringBuilder[numRows];
    for (int i = 0; i < numRows; i++) rows[i] = new StringBuilder();
    int r = 0, dir = 1;
    for (char c : s.toCharArray()) {
        rows[r].append(c);
        if (r == 0) dir = 1;
        else if (r == numRows - 1) dir = -1;
        r += dir;
    }
    StringBuilder ans = new StringBuilder();
    for (StringBuilder row : rows) ans.append(row);
    return ans.toString();
}
```
