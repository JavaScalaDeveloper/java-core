# PDP 测试表填写指南（Java 开发 · INTJ）

对应文件：`PDP测试表.xlsx`  
前提：已向用人单位说明 **MBTI 为 INTJ** — 填写须 **前后一致**，不宜填成「孔雀型社交达人」。

---

## 一、表在测什么？

PDP 把行为特质分成四类（常称「动物型」）：

| 类型 | 动物 | 特质关键词 |
|------|------|------------|
| **A** | 老虎 | 决断、目标、竞争、坚持 |
| **B** | 孔雀 | 表达、说服、活跃、焦点 |
| **C** | 考拉 | 温和、和谐、稳健、耐心 |
| **D** | 猫头鹰 | 严谨、分析、谨慎、精准 |

Java 开发岗 HR 通常希望看到：**猫头鹰（质量/逻辑）+ 适度老虎（能推进）+ 考拉（能协作）**，孔雀不必高。

---

## 二、填写规则（表格硬性约束）

| 规则 | 说明 |
|------|------|
| ① 每组 A/B/C/D 各填 **1、3、5、7** 之一 | **7 = 最像自己**，**1 = 最不像** |
| ② 每组 **1/3/5/7 各用一次** | 不能重复、不能缺 |
| ③ 汇总 A/B/C/D 四类得分 | **总分必须 = 80**，且 **A/B/C/D 各自总分均为奇数** |

数学原理：5 组 × 每组 (1+3+5+7) = **80 分**。

---

## 三、INTJ + Java 岗：推荐得分结构

| 类型 | 建议总分 | 画像 |
|------|----------|------|
| **D 猫头鹰** | **29**（最高） | 严谨、重思考、追精准 — 契合 INTJ 与写代码 |
| **A 老虎** | **23** | 有主见、能决断 — 不写成「独断专横」 |
| **C 考拉** | **17** | 稳定、能配合 — 表示 **可协作**，非「老好人」 |
| **B 孔雀** | **11**（最低） | 不抢焦点 — 与 INTJ 一致；可保留 **1 项 7** 表示「该沟通时能讲清楚」 |

**结果类型口述：** 「偏 **猫头鹰**，带 **老虎** 特质，整合型/变色龙向」— 技术岗友好。

---

## 四、推荐填法（可直接抄进 Excel）

在「自我评分」列填入下列数字（每组四个数各出现 1/3/5/7 一次）：

| 组别 | A | B | C | D | 对应描述（填时心里对照） |
|------|---|---|---|---|--------------------------|
| **第一组** | 5 | **1** | 3 | **7** | 坚定中等；**不爱表现**；温和一般；**谦虚严谨偏猫头鹰** |
| **第二组** | 3 | **1** | **5** | **7** | 冒险偏低；不抢焦点；**稳健**；**严谨考究最高** |
| **第三组** | **7** | **1** | 3 | 5 | **决心决断高**；不攻心表演；和谐一般；谨慎 |
| **第四组** | 3 | **1** | **5** | **7** | 竞争中等；**不淘气外露**；稳健协作；**重思考最高** |
| **第五组** | **5** | **3** | **1** | **7** | **果断**；**乐观有、交际弱**（B=3 折中）；情绪泛化描述偏低；**追精准最高** |

> **第五组说明：** B 项把「积极乐观 + 善于交际」绑在一起，无法拆开填。  
> - **B=1**：交际不像 ✓，但乐观也被打成「最不像」  
> - **B=3**：整体 **略偏不像/一般**，更符合「乐观可以、交际不行」  
> - **B=7**：仅当面试强调「能主动社交」时用，与 INTJ 已披露信息冲突风险大  

> **全表 B 全 1 的版本**（第五组 B=1）：规则合法、总分 80，但 B 合计仅 **5**，HR 可能解读为「完全不愿协作」——Java 岗建议 B 合计 ≥ **7**。

> **每组自验：** 四格必须是 `{1,3,5,7}` 各出现一次。

### 汇总（填完自验）

| 类型 | 得分 | 计算 |
|------|------|------|
| A 老虎 | **23** | 5+3+7+3+5 |
| B 孔雀 | **7** | 1+1+1+1+3 |
| C 考拉 | **17** | 3+5+3+5+1 |
| D 猫头鹰 | **33** | 7+7+5+7+7 |
| **合计** | **80** | ✓ 且四项均为奇数 ✓ |

### 每组是否含 1/3/5/7（必查）

| 组 | A | B | C | D | 是否合法 |
|----|---|---|---|---|----------|
| 一 | 5 | 1 | 3 | 7 | ✓ |
| 二 | 3 | 1 | 5 | 7 | ✓ |
| 三 | 7 | 1 | 3 | 5 | ✓ |
| 四 | 3 | 1 | 5 | 7 | ✓ |
| 五 | 5 | 3 | 1 | 7 | ✓ |

## 五、每组怎么理解（避免填反）

| 组 | 最该打 7 的项 | 最该打 1 的项 |
|----|---------------|---------------|
| 一 | **D** 严谨包容 | **B** 喜好表现 |
| 二 | **D** 严谨考究 | **B** 群体焦点 |
| 三 | **A** 决断力 | **B** 擅于攻心/表演 |
| 四 | **D** 重视思考 | **B** 调皮外露 |
| 五 | **D=7** 追求精准 | **C=1** 泛情绪描述；**B=3** 乐观可、交际弱 |

**原则：** 描述里带 **严格、思考、精准、谨慎、决断** → 偏高；带 **表现、焦点、调皮、攻心** → 偏低（第五组 B 除外）。

## 六、与 INTJ 已披露信息如何对齐

| 你已说 | PDP 应体现 | 避免 |
|--------|------------|------|
| INTJ 内向 | B 总分低 | B 三项 7、总分 >20 |
| 逻辑、架构 | D 最高 | D 低于 C |
| 能独立推进 | A 第二 | A 低于 15 |
| 程序员要协作 | C 中等 | C 全 1（像完全不合群） |

面聊若被问 PDP：**「猫头鹰为主，做事偏分析和标准；老虎体现在方案定了会推进；不是爱社交的类型，但项目里该对齐的会对齐。」**

## 七、Java 开发岗「被录取」在测什么？

HR 往往不是找「最像某种动物的人」，而是筛：

| 维度 | 填表策略 |
|------|----------|
| 稳定可靠 | C 别太低；D 高 = 少低级错误 |
| 能沟通 | 第五组 **B=3**（乐观有、交际不突出），不必强行 B=7 |
| 能负责 | A 有 **7**（第三组决断） |
| 不极端 | 不要 A、D 全 7、B 全 1 到像「无法团队合作」 |
| 一致性 | 与 INTJ、简历、面试表现 **同一套人设** |

**没有「标准答案表」**；上面方案是在 **规则合法 + 类型一致 + 岗位匹配** 下的推荐解。

## 八、填完检查清单

- [ ] 每组 1、3、5、7 各出现 **恰好 1 次**
- [ ] A+B+C+D 总分 = **80**
- [ ] A、B、C、D 各自总分都是 **奇数**
- [ ] D ≥ A > C > B（本推荐：29 > 23 > 17 > 11）
- [ ] 与已说的 **INTJ** 不矛盾
- [ ] 签名、日期已填

---

## 九、若需微调

在 **总分仍 80、各项仍为奇数** 前提下，只能在组内 **对调两个选项的分数**（例如某组 A 的 5 与 C 的 3 互换）：

- 想 **再强技术感**：略抬 D、略降 B（B 最低保持 ≥9）
- 想 **略强协作感**：C 从 17 提到 19，B 从 11 提到 9（需整组重排，用 Excel 试算）

**禁止：** 同组重复分数、总分不是 80、四项出现偶数 — 一眼会被判无效。
