### 知识地图
- 理论：CAP/BASE、一致性哈希、Raft/Paxos 直觉
- 工程：分布式锁、分布式 ID、事务、配置中心、RPC

### 常漏追问
1. **Redis 锁为何要续期？** 避免业务未完成锁过期；Redisson 看门狗常见。
2. **分布式事务优先什么？** 能避免则避免；本地消息表/Outbox 往往更稳。
3. **RPC 比 HTTP 多解决什么？** 服务发现、负载、序列化、治理。
