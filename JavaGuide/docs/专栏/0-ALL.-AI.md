### 复习方法
- 先看本目录重点篇，再按项目需要深挖。
- 对每个主题准备：是什么 / 为什么 / 怎么做 / 对比 / 坑。

### 工程落地检查清单
- [ ] 是否有明确指标（延迟、吞吐、错误率、积压）？
- [ ] 失败是否可重试且幂等？
- [ ] 是否有限流/超时/降级？
- [ ] 是否有日志、链路追踪与告警？
- [ ] 配置变更与回滚是否可操作？
